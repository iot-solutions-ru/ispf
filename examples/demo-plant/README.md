# Демо-завод

Это завод-шаблон на коробке MES. Его открывают, смотрят линию `LINE-A01` и отсюда создают завод заказчика.

Настоящий завод — форк этого каталога, а не вторая установка коробки:

```bash
node tools/ispf-cli/bin/ispf.mjs fork examples/demo-plant examples/<plant> --app-id <plant-id>
```

Форк получает свою схему `app_<plant-id>`. Дальше в нём меняют маршрут, паспорт партии и экран. Пример такого завода: `examples/plant-discrete-mes` (колонка `passport_note`).

Демо-линия лежит в `seeds/` и попадает в базу только с `--with-seeds`. Без этого флага схема пустая.
