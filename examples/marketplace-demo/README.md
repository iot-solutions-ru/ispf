# Marketplace demo

A small bundle used to check that a marketplace install comes up. Schema `app_marketplace_demo`. One note row and an operator dashboard.

Небольшой пакет, чтобы проверить установку из маркетплейса. Схема `app_marketplace_demo`. Одна строка-заметка и экран оператора.

Deploy [`bundle.json`](bundle.json) as application `marketplace-demo`.
