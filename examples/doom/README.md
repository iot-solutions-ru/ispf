# DOOM on ISPF

Freedoom, packaged as a hosted page. It shows that a ui-pack is an ordinary web app. It is not a plant solution.

Freedoom в виде размещённой страницы. Пример того, что ui-pack — обычное веб-приложение. К производству не относится.

ISPF serves it at `/apps/doom/`. Manifest: [`ui-pack.json`](ui-pack.json).
