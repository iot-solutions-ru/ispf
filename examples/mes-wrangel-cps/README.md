# Raw-material workshop

Shift accounting for one named site (Wrangel Mineral): equipment from the brief, reference data, a mimic, and shift reports. Schema `app_mes_wrangel`. This bundle expects that site's signals. It is not a laptop-only toy.

Посменный учёт одного цеха (ВрангельМинерал): оборудование из задания, справочники, мнемосхема и сменные отчёты. Схема `app_mes_wrangel`. Пакет рассчитан на сигналы этой площадки, а не на пустой ноутбук.

The operator screen is [mes-wrangel-ui](../mes-wrangel-ui/). Deploy [`bundle.json`](bundle.json) as application `mes-wrangel-cps`.
