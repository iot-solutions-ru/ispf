# Solution checks

Python scripts that score a lab server: local tests, restart gates, and a faceplate seed. This folder is not deployed as an application.

Скрипты Python, которые оценивают лабораторный сервер: локальные тесты, перезапуски и загрузка лицевой панели. Как приложение это не разворачивается.

The list of checks is [`ops-manifest.json`](ops-manifest.json).
