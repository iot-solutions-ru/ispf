# MQTT temperature lab

Four temperature sensors published over MQTT, with a registry table and a map. Schema `mqtt_temperature_lab`. You need a broker; you do not need a controller.

Четыре датчика температуры по MQTT, таблица реестра и карта. Схема `mqtt_temperature_lab`. Нужен брокер, контроллер не нужен.

Deploy [`bundle.json`](bundle.json). The broker host in the bundle metadata is a placeholder (`mqtt-broker.example.invalid`).
