# Third-Party Notices

The ISPF distribution includes third-party components licensed differently from ISPF code. When distributing source or binary builds, retain [LICENSE](../../LICENSE), [NOTICE](../../NOTICE), this file, and license/notice files of dependencies themselves.

This document is an engineering inventory, not legal advice. For public release or commercial delivery, generate an SBOM and obtain legal review.

## ISPF licensing policy

Platform code in the repository is licensed under **GNU AGPL-3.0** ([0016-agpl-dual-licensing](decisions/0016-agpl-dual-licensing.md)). Third-party libraries retain their own licenses.

Current delivery state:

- **Platform (`ispf-server`, `web-console`, core packages):** AGPL-3.0; Enterprise — optional `platform-license.json`.
- **Device drivers:** only **driver packs** in `${ISPF_DRIVER_PACKS_DIR}`; each pack has its own `LICENSE` and `licenseType`.
- **Protocol stacks formerly GPL/commercial** (BACnet, DLMS, IEC-104, DNP3, IPMI, RADIUS, M-Bus): replaced by **ISPF-owned clean-room codecs** (Apache-2.0 pack license). No bacnet4j / Gurux / j60870 / StepFunc / vxIPMI / TinyRadius / jMBus on the classpath.
- **Web console spreadsheet:** built-in MIT/AGPL formula engine (`ispfSheetEval`); HyperFormula is **not used**.
- **Report templates:** Apache POI Band1 filler only (ADR-0053). YARG / JasperReports / docx4j report path **removed**.
- **Application bundles:** declarative JSON + customer EULA; not platform "source code" under AGPL.

## Project license recommendation

1. **Platform** — AGPL-3.0; network use triggers source-offer unless Enterprise EULA applies.
2. **Drivers** — pack-only runtime; protocol codecs are ISPF-owned Apache-2.0 (except SIP NIST public-domain RI).
3. **Web console** — AGPL; spreadsheet uses built-in `ispfSheetEval`.
4. **Commercial/closed scenario:** Enterprise platform license + application bundles under separate EULA.

## SBOM generation and pre-release CI

```bash
node tools/license-audit/check-all.mjs
node tools/license-audit/generate-sbom.mjs
```

Recommended release process:

1. Generate CycloneDX SBOM + engineering legal review (`generate-sbom.mjs`).
2. Confirm driver packs are Apache-2.0 (or NIST SIP) — no GPL/LGPL/MPL/StepFunc pack `licenseType`.
3. Confirm server runtime has no YARG/JasperReports/docx4j.
4. Attach `LICENSE`, `NOTICE`, this file, and SBOMs to binary distribution.
