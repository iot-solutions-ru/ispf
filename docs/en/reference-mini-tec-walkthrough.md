# Reference Walkthrough: Mini-CHP Power Plant SCADA (`mini-tec`)

> **Status:** Lab — comprehensive SCADA and power-plant dispatch reference bundle with 3 gas piston units, gas pressure reduction, 10/0.4 kV switchgear, diesel backup, protection interlocks, and single-line mimic diagrams. Status tags: [doc-status.md](doc-status.md).

The **`mini-tec`** reference solution ([`examples/mini-tec/`](../../examples/mini-tec/), `appId = "mini-tec"`) demonstrates a complete SCADA and dispatch system for a 4,440 kW gas-piston combined heat and power (CHP) station built entirely with ISPF object tree mechanisms.

---

## 1. Plant Equipment in the Object Tree

| Equipment / Node | Object Tree Path | Blueprint (`BlueprintType`) |
|------------------|------------------|-----------------------------|
| **Gas Piston Units (GPU 1–3)** | `root.platform.devices.mini-tec-plant.gpu-01` .. `gpu-03` | `mini-tec-gpu-v1` (`INSTANCE`) |
| **Gas Pressure Reduction Block (GRPB)** | `root.platform.devices.mini-tec-plant.grpb` | `mini-tec-grpb-v1` (`INSTANCE`) |
| **10/0.4 kV Switchgear (RUMB)** | `root.platform.devices.mini-tec-plant.rumb-10kv` | `mini-tec-rumb-v1` (`INSTANCE`) |
| **Diesel Generator Unit (DGU)** | `root.platform.devices.mini-tec-plant.dgu` | `mini-tec-dgu-v1` (`INSTANCE`) |
| **Load Bank Module** | `root.platform.devices.mini-tec-plant.load-module` | `mini-tec-load-module-v1` (`INSTANCE`) |
| **Station Orchestrator Hub** | `root.platform.devices.mini-tec-plant.station-hub` | `mini-tec-station-hub-v1` (`SINGLETON`) |

Total installed capacity is **4,440 kW** (`3 × 1,480 kW`). In demo mode, telemetry is generated by the `virtual` driver profiles `tec-gpu`, `tec-grpb`, `tec-rumb`, `tec-dgu`, and `tec-load`.

## 2. Walkthrough Scenario Steps

| Step | Action | UI / API | Result |
|------|--------|----------|--------|
| 1 | Deploy or bootstrap | `MiniTecPlatformBootstrap` or `POST /api/v1/applications/mini-tec/deploy` | Creates blueprints, plant nodes, dashboards, mimics, BPMN workflows, and operator menus |
| 2 | Open Operator HMI | `?mode=operator&app=mini-tec` | Opens the integrated single-line mimic dashboard `mini-tec-hmi` with top alarm bar |
| 3 | Switch process zones | Tabs **Generation**, **Gas**, **Electrical supply** | Displays mimics `mini-tec-single-line`, `mini-tec-zone-gas`, and `mini-tec-zone-electrical` |
| 4 | Inspect a unit | Click any unit on the mimic (`setSelection`) | Updates the right-hand detail card with live power, status, 1h sparkline, and start/stop controls |
| 5 | Trigger training fire protection | Invoke `simulate_fire` on `grpb` | Raises emergency alarm and triggers the gas-trip BPMN workflow shutting down all three GPUs |
| 6 | Trigger underpower load shedding | Consumer load exceeds active generation | Correlator detects `stationUnderpower` and runs workflow `mini-tec-load-module-auto-unload` |
| 7 | Daily station log | Schedule `mini-tec-daily-journal-etl` | Function `aggregate_daily_journal` writes daily summaries into `tec_daily_journal` |

---

## 3. Zone-Based Operator Access Control (`ACL`)

- `operator-gas` has `OWNER` permissions on the gas block (`grpb`), but is denied access (`403 Forbidden`) to electrical switchgear variables (`rumb-10kv`).
- `operator-electrical` controls `rumb-10kv` and `load-module`.
- `operator-engineer` has station-wide access and executes the shift-handover workflow `mini-tec-shift-handover`.
