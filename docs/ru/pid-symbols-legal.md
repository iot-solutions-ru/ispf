# Правовой статус встроенной библиотеки символов P&ID (`ispf-pid-v1`)

> **Статус:** Stable — происхождение и лицензия векторных символов технологических схем SCADA. Метки зрелости: [doc-status.md](doc-status.md).

Встроенный набор графических символов мнемосхем **`ispf-pid-v1`** (`apps/web-console/src/scada/symbols/packs/ispf-pid-v1/`) целиком создан внутри проекта ISPF с помощью собственного генератора [`tools/symbol-pack-isa/`](../../tools/symbol-pack-isa/) и распространяется под открытой лицензией **Apache-2.0**.

---

## Основные сведения о библиотеке символов

| Характеристика | Описание |
|----------------|----------|
| **Происхождение графики** | Собственная векторная отрисовка в коде `tools/symbol-pack-isa/src/symbols.ts` (координатная сетка `64×64`, поддержка CSS-переменных темы оформления); заимствованные графические файлы сторонних SCADA-систем не используются |
| **Применяемые стандарты** | Общепринятые функциональные обозначения по стандартам **ISA-5.1 / ISO 14617** (задвижки, клапаны, насосы, резервуары, теплообменники, контуры приборов КИПиА `PI`, `TI`, `FT`) |
| **Лицензия пакета** | **Apache-2.0** ([паспорт лицензии символов](../../apps/web-console/src/scada/symbols/packs/ispf-pid-v1/LICENSE.md)) |

Команда для пересборки SVG-файлов библиотеки из исходного генератора:

```bash
cd tools/symbol-pack-isa && npm install && npm run build
```
