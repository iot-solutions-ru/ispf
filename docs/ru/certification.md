# Обучение и сертификация инженеров ISPF

> **Статус:** Stable — программы подготовки разработчиков прикладных решений и системных администраторов платформы, лабораторные задания и проверочные вопросы (`examples/certification/`). Метки зрелости: [doc-status.md](doc-status.md).

Программа сертификации ISPF состоит из двух основных инженерных треков с практическими лабораторными работами, которые можно выполнить на локальном сервере или учебном стенде. Перед началом рекомендуется пройти стартовый маршрут **[Как устроен ISPF (`learn.md`)](learn.md)**.

**Связанные разделы:** [Партнёрская программа (`partner-program.md`)](partner-program.md) · [Практический курс из 18 упражнений (`lab-training.md`)](lab-training.md) · [Руководство разработчика решений (`solution-developer-guide.md`)](solution-developer-guide.md).

---

## 1. Обзор треков подготовки

| Трек | Целевая аудитория | Итоговая квалификация |
|------|-------------------|-----------------------|
| **1. Разработчик прикладных решений (`Solution Developer`)** | Инженеры АСУ ТП, интеграторы, разработчики SCADA / MES | Самостоятельное проектирование дерева объектов, шаблонов, правил расчёта, мнемосхем, процессов BPMN и сборка пакета `bundle.json` |
| **2. Администратор платформы (`Platform Admin`)** | Системные администраторы, инженеры ИТ/ОТ и DevOps | Промышленное развёртывание, настройка OIDC/RBAC/ACL, архив историй (TimescaleDB / ClickHouse), кластер высокой доступности и мониторинг |

### Уровень 3 — Масштабируемые решения и ИИ-инструменты (~32 часа)

## 4. Контрольные банки вопросов в репозитории (`examples/certification/`)

Для самопроверки знаний в репозитории размещены машиночитаемые наборы тестовых вопросов в формате JSON:

| Файл банка вопросов | Трек и уровень | Количество вопросов |
|---------------------|----------------|:-------------------:|
| [`examples/certification/solution-developer-l1.json`](../../examples/certification/solution-developer-l1.json) | Разработчик решений — Уровень 1 | 8 |
| [`examples/certification/solution-developer-l2.json`](../../examples/certification/solution-developer-l2.json) | Разработчик решений — Уровень 2 | 6 |
| [`examples/certification/platform-admin-core.json`](../../examples/certification/platform-admin-core.json) | Администратор платформы — Базовый курс | 8 |

Проверка и прогон с этой машины, после `npm install` в `tools/ispf-cli`:

```bash
node tools/ispf-cli/bin/ispf.mjs cert check examples/certification/solution-developer-l1.json
node tools/ispf-cli/bin/ispf.mjs cert run examples/certification/solution-developer-l1.json
```

`cert check` проверяет файл и печатает `ok <число>`. `cert run` печатает вопрос и читает номер варианта (1, 2, 3, …). Неверный ответ — строка `miss <id> <reference>`, последняя строка — `<верно>/<всего>`. Код выхода 1, если есть неверный ответ. Без терминала передайте `--answers <file>`: объект JSON, значение — тот же индекс с нуля, что `correctIndex`. Команда не обращается к серверу. Практические работы в этот счёт не входят.
