# Программа инженерного ускорения и стабилизации (спринты S19–S23)

> **Статус:** Internal — архивный отчёт о выполнении 8-недельной программы стабилизации CI, ускорения интерфейса, федерации и семантической разметки. Метки зрелости: [doc-status.md](doc-status.md).

Этот документ фиксирует целевые показатели и итоги внутренней программы инженерного ускорения (спринты S19–S23), выполненной летом 2026 года.

---

## Основные достигнутые результаты по направлениям

| Спринт | Направление | Что было сделано |
|--------|-------------|------------------|
| **S19** | Замер базовых показателей | Зафиксированы базовые метрики времени сборки PR, пропускной способности конвейера событий и скорости отрисовки интерфейса (`tools/acceleration/collect-baseline.py`) |
| **S20** | Скорость и надёжность CI | Разделены быстрый пред-PR конвейер (`pr-fast` ≤ 25 минут) и полный ночной прогон (`nightly.yml`), введён регламент устранения нестабильных тестов ([ci-flaky-triage.md](ci-flaky-triage.md)) |
| **S21** | Производительность и доступность веб-консоли | Внедрены автоматические проверки размера сборки (`bundle:budget`), доступности (Lighthouse / axe) и частоты кадров на мнемосхемах из 500 элементов ([hmi-quality-gates.md](hmi-quality-gates.md)) |
| **S22** | Надёжность федерации площадок | Реализована выборочная синхронизация ветвей дерева (`sync-subtree`), буферизация событий при обрыве связи и автотесты восстановления ([federation.md](federation.md)) |
| **S23** | Семантическая разметка оборудования | Добавлено автоопределение классов Brick Schema и быстрая привязка виджетов дашборда по тегам Project Haystack ([semantic-demo.md](semantic-demo.md)) |
