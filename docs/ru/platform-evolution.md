# История развития архитектуры ISPF (ретроспектива версий)

> **Статус:** Stable — хронологический обзор того, как формировались ключевые подсистемы платформы от первых коммитов до современного состояния. Метки зрелости: [doc-status.md](doc-status.md).

Этот документ кратко показывает эволюцию технических механизмов ISPF по крупным вехам развития. Полный журнал релизов ведётся в файле **[Журнал изменений (`changelog.md`)](changelog.md)**, а текущий план работ — в **[Дорожной карте (`roadmap.md`)](roadmap.md)**.

---

## Ключевые архитектурные вехи

| Версия | Главный архитектурный шаг |
|--------|---------------------------|
| **v0.1.x** | Создание единого дерева объектов (`root.platform.*`), типизированных переменных (`DataRecord` / `DataSchema`), вычислителя выражений Google CEL, первых протокольных драйверов, конструктора дашбордов и движка процессов BPMN |
| **v0.2.0** | Чёткое разделение универсального ядра сервера и прикладных решений: введение пакетов `bundle.json`, изолированных SQL-схем приложений, скриптовых функций и единого шлюза BFF ([ADR-0001](decisions/0001-app-platform-boundary.md)) |
| **v0.3.0 – v0.5.x** | Федерация серверов (`Hub ↔ Edge`), синхронизация каталогов, точечная привязка удалённых узлов и исходящие WebSocket-туннели для площадок за NAT ([federation.md](federation.md)) |
| **v0.6.0 – v0.7.x** | Сохранение состояния реактивных функций (`@bindingState`), запуск встроенной ИИ-студии, пошагового агента дерева объектов, адаптера MCP и модульных пакетов драйверов (`driver-pack`) |
| **v0.8.x** | Переход на единый массив правил расчёта `@bindingRules` (`BindingRuleEngine`), визуальные группы объектов и комплексный эталонный стенд АСУ ТП мини-ТЭЦ |
| **v0.9.x** | Горизонтальный кластер высокой доступности с синхронизацией через NATS и Redis ([cluster.md](cluster.md)), трёхуровневый архив историй с поддержкой ClickHouse и Parquet ([historian-tiers.md](historian-tiers.md)), собственный векторный редактор BPMN, размещение внешних React-приложений (`ui-pack`) и формальная проверка выражений CEL через решатель Z3 |
