# Автоматический контроль производительности и доступности веб-консоли

> **Статус:** Lab — автоматические проверки размера сборки фронтенда, доступности интерфейса (Lighthouse и axe) и частоты кадров (FPS) на сложных мнемосхемах SCADA. Метки зрелости: [doc-status.md](doc-status.md).

Чтобы экраны оператора работали плавно даже на загруженных мнемосхемах с сотнями динамических элементов, в `apps/web-console` настроен набор автоматических проверок качества интерфейса.

---

## 1. Набор проверок и команды запуска

```bash
cd apps/web-console
npm run build
npm run bundle:budget
npm run lighthouse:ci
npm run test:quality
```

| Проверка | Команда | Что контролирует |
|----------|---------|------------------|
| **Контроль размера сборки** | `npm run bundle:budget` | Проверяет, что размер скомпилированных JS/CSS-файлов не превышает лимитов, заданных в `scripts/bundle-budget.json` |
| **Аудит Lighthouse** | `npm run lighthouse:ci` | Оценка производительности и доступности (`Accessibility` ≥ 90 для режима оператора) |
| **Проверка доступности (axe)** | `npm run test:quality` | Отсутствие критических нарушений контрастности текста (`--text-muted`), клавиатурной навигации и атрибутов `role="alert"` / `aria-live` на панели тревог |
| **Частота кадров мнемосхемы (FPS)** | `npm run test:quality` | Плавность отрисовки холста `ScadaMimicCanvas` на нагрузочной схеме из **500 элементов** (`e2e/fixtures/stressMimic.ts`, целевой порог локальной приёмки ≥ 55 кадр/с в статике и ≥ 35 кадр/с при непрерывном потоке обновлений `VARIABLE_UPDATED` по WebSocket) |

---

## 2. Настройка порогов через переменные окружения

При запуске `npm run test:quality` (`playwright.quality.config.ts`) пороговые значения можно переопределить переменными окружения:
- `MIMIC_STRESS_ELEMENTS` — количество элементов на тестовой мнемосхеме (по умолчанию `500`);
- `MIMIC_MIN_FPS` — минимальная частота кадров при панорамировании и масштабировании (по умолчанию `55`);
- `MIMIC_MIN_FPS_WS` — минимальная частота кадров при интенсивном потоке обновлений по WebSocket (по умолчанию `35`);
- `LH_MIN_ACCESSIBILITY_OPERATOR` — минимальный балл доступности экрана оператора в Lighthouse (по умолчанию `90`).
