# Отчёт инженерной проверки состава программных компонентов (SBOM)

> **Статус:** Stable — сводный отчёт автоматического аудита лицензий зависимостей Java (`ispf-server`), npm (`apps/web-console`) и пакетов драйверов. Метки зрелости: [doc-status.md](doc-status.md).

Отчёт формируется автоматически скриптом `node tools/license-audit/generate-sbom.mjs` по спецификациям CycloneDX 1.5.

---

## 1. Итоги проверки зависимостей

- В каталоге драйверов и серверном ядре **отсутствуют** сторонние библиотеки под лицензиями `GPL` или закрытыми некоммерческими лицензиями (протоколы BACnet, DLMS, МЭК-104, DNP3, IPMI, RADIUS, M-Bus работают на собственных кодеках ISPF под лицензией `Apache-2.0`).
- Подсистема отчётов использует только библиотеку `Apache POI` (`Apache-2.0`).
- Транзитивные библиотеки инфраструктуры Spring Boot / Jakarta EE с разрешительными условиями компоновки (`EPL-2.0`, `GPL-2.0-with-classpath-exception`) перечислены в разделе уведомлений с сохранением штатных атрибуций правообладателей.

| Область проверки | Проверено пакетов | Критических замечаний (`High` / `Medium`) |
|------------------|------------------:|------------------------------------------:|
| Зависимости фронтенда (`npm`, `apps/web-console`) | 931 | 0 / 0 |
| Зависимости сервера (`Java runtimeClasspath`) | 260 | 0 / 0 |
| Пакеты драйверов в профиле `permissive` | все пакеты каталога | 0 / 0 |

---

## 2. Генерируемые артефакты SBOM (`build/sbom/`)

- `web-console.cdx.json` — перечень npm-пакетов веб-консоли в формате CycloneDX 1.5;
- `ispf-server-runtime.cdx.json` — перечень Java-зависимостей сервера в формате CycloneDX 1.5;
- `driver-packs.cdx.json` — перечень зависимостей модульных пакетов драйверов;
- `legal-review.json` — машиночитаемая сводка проверки лицензий.

Полная таблица транзитивных библиотек приведена в английской версии отчёта: **[en/sbom-legal-review.md](../en/sbom-legal-review.md)**.
