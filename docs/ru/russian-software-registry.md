# Включение ISPF в Единый реестр российского ПО Минцифры России

> **Статус:** Internal — памятка для правообладателя по подготовке комплекта документов и дистрибутива для подачи заявления на [reestr.digital.gov.ru](https://reestr.digital.gov.ru). Метки зрелости: [doc-status.md](doc-status.md).

Этот документ описывает состав технического пакета, классификацию продукта и порядок подготовки эталонного дистрибутива ISPF для прохождения экспертизы Минцифры России.

> **Примечание:** документ носит справочно-инженерный характер и не заменяет юридической проверки договоров и структуры владения организации-заявителя.

**Связанные разделы:** [Обзор продукта](product.md) · [Развёртывание и конфигурация](deployment.md) · [Лицензионная чистота и сторонние компоненты](license-compliance.md) · [Уведомления об открытых компонентах](third-party-notices.md).

| Преимущество | Правовое основание |
|--------------|--------------------|

## 3. Требования к организации-правообладателю

Перед подачей заявки проверьте соблюдение базовых требований п. 5 Правил (ПП РФ № 1236):
1. Заявитель — российское юридическое лицо с преобладающим участием граждан или организаций РФ (более 50 %).
2. Исключительные права на программный комплекс оформлены на заявителя на всей территории мира и на весь срок действия права (служебные задания, акты приёма-передачи или договоры отчуждения, свидетельство Роспатента о регистрации программы для ЭВМ).
3. Сумма лицензионных отчислений в пользу иностранных правообладателей не превышает установленного Правилами порога (в промышленной поставке ISPF используются только открытые библиотеки со свободными лицензиями — см. [Лицензионная чистота](license-compliance.md)).
4. На официальном сайте правообладателя опубликована страница продукта с описанием функциональных возможностей, системными требованиями, условиями лицензирования и инструкцией по установке.

node tools/registry-techpack/build-techpack.mjs \

  --product-url "https://example.com/products/ispf" \

## 6. Подготовка дистрибутива и контрольного сценария для эксперта

Для проведения экспертизы рекомендуется предоставить **автономный архив установки без интернета (`air-gap`)** по инструкции **[Установка в закрытом контуре (`air-gap-deployment.md`)](air-gap-deployment.md)** либо однофайловую сборку `ispf-server.jar` со встроенной веб-консолью.

### Системные требования для проверочной виртуальной машины эксперта

| Компонент | Минимальные требования | Рекомендуемые |
|-----------|------------------------|---------------|
| Процессор и память | 4 vCPU, 8 ГБ ОЗУ, 50 ГБ на диске | 8 vCPU, 16 ГБ ОЗУ, SSD |
| Операционная система | Linux x86_64 (Astra Linux SE, РЕД ОС, Альт Сервер, Ubuntu 22.04/24.04) | Отечественная серверная ОС из реестра или Ubuntu 24.04 LTS |
| Среда исполнения | Temurin / OpenJDK 25 (включена в контейнерный образ) | JDK 25 |
| СУБД | PostgreSQL 16 (или встроенная файловая БД H2 для быстрого ознакомления) | PostgreSQL 16 + TimescaleDB |
| Браузер рабочей станции | Яндекс Браузер, Chromium, Firefox | Разрешение экрана 1920×1080 |

### Краткий контрольный сценарий проверки экспертом (~30 минут)

1. Запустить сервер и убедиться, что `GET /actuator/health` возвращает `"status": "UP"`, а `GET /api/v1/info` — номер версии.
2. Войти в веб-консоль под учётной записью администратора (`admin`) и открыть дерево объектов `root.platform.devices`.
3. Импортировать демонстрационный учебный пакет `examples/lab-training/bundle.json` (или пакет мини-ТЭЦ `examples/mini-tec/bundle.json`).
4. Проверить обновление живых показаний на дашборде и мнемосхеме по WebSocket.
5. Открыть график истории переменной за выбранный период и выгрузить выборку в CSV.
6. Вызвать срабатывание правила тревоги и проверить появление записи в журнале событий.
7. Выполнить запуск процесса BPMN и закрыть поступившую задачу в рабочей очереди оператора (`Work Queue`).
8. Сформировать табличный отчёт в разделе `root.platform.reports` и скачать его в формате XLSX или PDF.
9. Войти под учётной записью дежурного оператора (`operator`) и убедиться, что открывается полноэкранный пульт оператора без доступа к редактированию системных настроек.
