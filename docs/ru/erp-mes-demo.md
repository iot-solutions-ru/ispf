# ERP-MES: как пользоваться на демо

Стенд: **[https://mes.iot-solutions.ru/](https://mes.iot-solutions.ru/)**  
Логин: `admin` / `admin` (или `operator` / `operator`)

Ниже — **что открывать и какие кнопки жать**, чтобы повторить все процессы end-to-end.

---

## Как устроен UI

1. После логина откройте **режим оператора**:
   - либо кнопка перехода к приложениям оператора,
   - либо URL: `https://mes.iot-solutions.ru/?lang=ru&mode=operator`
2. На сетке три карточки — клик по карточке открывает приложение.
3. Внутри приложения сверху **вкладки** (сегментированное меню) — это дашборды.
4. В таблицах выбирайте строку **радиокнопкой** слева — от этого зависят формы и кнопки справа.
5. Кнопки **Пауза / Возобновить / Запустить / Завершить** активны только при подходящем статусе выбранного задания.

Вернуться к сетке приложений: кнопка **«Консоль администратора»** не нужна — откройте снова  
`?mode=operator` или уберите `&app=...` из URL.

## A. MES Фарма — полный проход

### A0. Открыть

1. `mode=operator`
2. Клик: карточка **«MES Фарма (ISA-95/ISA-88)»**
3. Откроется вкладка **«Производство»**

---

### A1. KPI и Pause / Resume

![Фарма — вкладка «Производство»: KPI, задания, Пауза/Возобновить](../assets/erp-mes-demo-02-pharma-production.png)

| Шаг | Куда смотреть / что нажать | Ожидание |
|-----|----------------------------|----------|
| 1 | Верхние три карточки KPI | «Лотов на карантине», «Открытые девиации», «Серий в работе» — числа не все нули (через ~30 с) |
| 2 | Таблица «Задания» → радио **«Выбрать JO-PH-001»** | Строка Status = `RUNNING` (линия `TPR-01`) |
| 3 | Блок «Действия с заданием» → **Пауза** | Status → `SUSPENDED`; **Возобновить** становится активной **без повторного клика по строке** |
| 4 | **Возобновить** | Status снова `RUNNING`; снова активны **Пауза** и **Завершить** |

Если `JO-PH-001` уже `SUSPENDED`: сразу жмите **Возобновить**, потом снова **Пауза**.  
Если Status = `ALLOWED`: выберите `JO-PH-002` → **Запустить**.

---

### A2. Взвешивание GMP (опционально)

На той же вкладке **«Производство»**, форма внизу **«Взвешивание (GMP, 2-я подпись)»**:

| Поле | Значение |
|------|----------|
| Штрихкод серии | `BC-API-0002 - API-PARACETAMOL` (из списка) |
| Целевая масса | `100` |
| Фактическая масса | `100` (или 98–102) |
| Допуск, % | `2` |
| Взвесил | `EMP-H02 - Sergey Operator` |
| Проверил | `EMP-H01 - Olga Technologist` |

Кнопка: **«Проверить и подписать»** → сообщение об успехе.

---

### A3. Качество: дефект и выпуск серии

![Фарма — «Качество и выпуск серии»: карантин, девиации, формы релиза](../assets/erp-mes-demo-03-pharma-quality.png)

1. Вкладка сверху: **«Качество и выпуск серии»**
2. **Зарегистрировать дефект** (форма справа / ниже):

| Поле | Значение |
|------|----------|
| Дефект № | любой новый, напр. `DEMO-001` |
| Сменное задание | `JO-PH-001` |
| Тип дефекта | `DFT-WEIGHT-VAR` |
| Критичность | `MINOR` |
| Количество | `1` |
| Сотрудник | `EMP-H03` |

Кнопка регистрации дефекта → успех.  
Вернитесь на **«Производство»**: KPI «Открытые девиации» должен вырасти (через ~30 с или F5).

3. **Выпуск серии** (если в таблице карантина есть строка со статусом `QUARANTINE`):
   - клик по строке партии (радио),
   - форма **«Выпустить серию (релиз ОКК)»**,
   - подпишите / подтвердите,
   - в таблице: disposition `RELEASED`, склад **`WH-REL`**.

Если карантин пуст — процесс уже пройден ранее; покажите форму и поясните seed `LOT-FG-PH-0001` = `RELEASED` / `WH-REL`.

4. (Опционально) **Забраковать серию** — только на `QUARANTINE`; уйдёт в `WH-REJ`.

---

### A4. Генеалогия

![Фарма — генеалогия серии (reverse / forward)](../assets/erp-mes-demo-04-pharma-genealogy.png)

1. Вкладка **«Генеалогия серии»**
2. Смотрите таблицы / формы reverse / forward:
   - seed FG: `LOT-FG-PH-0001`
   - должны быть уровни цепочки (сырьё ↔ WIP ↔ FG)

---

### A5. Сериализация и MOM (по желанию)

| Вкладка | Что сделать |
|---------|-------------|
| **Сериализация и аудит** | открыть таблицы serial / e-sign — данные seed уже есть |
| **MOM 62264-3 (ядро)** | матрица 4×8, ячейки `COVERED` |

## B. MES Полиграфия — полный проход

### B0. Открыть

1. Вернитесь на `?mode=operator`
2. Клик: **«MES Полиграфия (ISA-95)»**
3. Вкладка по умолчанию: **«Диспетчер печати»**

---

### B1. KPI и задания

![Полиграфия — диспетчер печати: KPI и задания](../assets/erp-mes-demo-05-printing-dispatch.png)

| Шаг | Действие | Ожидание |
|-----|----------|----------|
| 1 | Смотрите KPI сверху | «Открыто простоев» ≥ 1, «Заданий в работе» ≥ 1, **«Рулонов ниже минимума» = 1** |
| 2 | Радио **JO-PRINT-001** | Status `RUNNING`, Equipment `PR120` |
| 3 | **Пауза** → **Возобновить** | как в Pharma |

---

### B2. Регистрация события / простоя

![Полиграфия — «События и простои»: регистрация OGP и каталог кодов](../assets/erp-mes-demo-06-printing-events.png)

1. Вкладка **«События и простои»**
2. Форма **«Зарегистрировать событие»**:

| Поле | Значение |
|------|----------|
| Код события | `OGP-119` (из списка каталога) |
| Задание | `JO-PRINT-001` |
| Оборудование | `PR120` |
| Длительность, мин | `5` |
| Метраж, м | **можно пусто** |
| Комментарий | любой текст |
| Кем | `operator` |

3. Кнопка **«Зарегистрировать»** → успех.  
4. KPI «Открыто простоев» на диспетчере может вырасти.

Закрытие (опционально): форма **«Закрыть событие»** → выбрать id из журнала → **«Закрыть»**.

---

### B3. Рулоны и генеалогия

| Вкладка | Что нажать / увидеть |
|---------|----------------------|
| **Рулоны и материалы** | в таблице есть `LOT-FILM-LOW` (мало метров) |
| **Генеалогия рулонов** | reverse FG sleeve / forward film — строки с `LOT-` |
| **MOM 62264-3 (ядро)** | та же матрица, что в Pharma |

## C. ERP-MES Core — нейтральный контур

![ERP-MES Core — диспетчер: KPI и сменные задания](../assets/erp-mes-demo-07-core-dispatch.png)

1. `mode=operator` → карточка **«ERP-MES Core (ISA-95)»**
2. Пройдите вкладки по кругу (только открыть и убедиться, что таблицы не пустые):

| Вкладка | Зачем |
|---------|--------|
| **Диспетчер** | job board ядра |
| **Исполнение** | consume / produce / PDC |
| **Склад** | stock |
| **Качество** | дефекты |
| **OEE и простои** | события / смены |
| **Генеалогия партии** | UPSTREAM/DOWNSTREAM (напр. `LOT-FG-0001`) |
| **MOM 62264-3** | матрица Part 3 |

Отдельные пункты меню вроде **Job Board**, **Stock**, **Defects** — это отчёты; достаточно кликнуть и показать таблицу.

## Если кнопка серая

| Кнопка | Когда активна |
|--------|----------------|
| **Запустить** | Status = `ALLOWED` |
| **Пауза** | Status = `RUNNING` |
| **Возобновить** | Status = `SUSPENDED` |
| **Завершить** | Status = `RUNNING` (и нет блокирующих дефектов) |

Сначала **выберите строку** радиокнопкой, потом жмите действие.

## Seed-шпаргалка (копипаст в формы)

```
Pharma job:     JO-PH-001
Pharma defect:  DFT-WEIGHT-VAR / EMP-H03 / qty 1
Weigh barcode:  BC-API-0002
Print job:      JO-PRINT-001 / PR120
Event code:     OGP-119
Low roll:       LOT-FILM-LOW
FG genealogy:   LOT-FG-PH-0001
```

## Если стенд «грязный»

| Ситуация | Действие |
|----------|----------|
| Нет `QUARANTINE` | пропустите релиз; дефект и Pause/Resume важнее |
| Job не RUNNING | Resume или Start на ALLOWED-строке |
| KPI = 0 | подождите 30 с, F5 |
| После Паузы Resume мёртв | F5, снова выбрать строку |
| Мешают алерты | **Подтвердить** / **Отложить 1ч** |
