## Куда идём

ISPF — **self-hosted платформа промышленных приложений**: одно дерево объектов, драйверы OT/IT, операторский HMI, автоматизация (события, BPMN-subset), приложения с BFF, маркетплейс и AI-слой для скорости интегратора.

Цель программы зрелости (фазы 25–33) — довести продукт до **10/10** по доменам IoT / SCADA / MES / ERP Level 4 / analytics относительно зрелых коммерческих платформ. Планка «10/10» — не чеклист фич, а **пригодный** продукт: полевой OT, живой ERP при необходимости, операторский HMI, честный scorecard. См. [Определение готовности](#определение-готовности--общая-оценка-1010) и [competitive-scorecard](competitive-scorecard.md).

ISPF **не** полный ERP (SAP/1C) и **не** Opcenter «всё в ядре». Level 4 — надёжные коннекторы ISA-95; MES — первоклассные объекты + сертифицированные bundles + полевые площадки.

## Политика исполнения — качество вместо фич {#политика-исполнения--качество-вместо-фич}

**Решение (19.07.2026):** сконцентрироваться на **качестве и честности** уже существующих возможностей. **Не** расширять поверхность фич (новые элементы BPMN, новые фазы, новые продуктовые линии), пока нет **именованного blocker от заказчика**.

| Работа по умолчанию | Не по умолчанию |
| ------------------- | --------------- |
| Field soak, live gates, runbook’и, честность CI | Новые типы элементов / движки «для полноты» |
| Частичный → Готово с доказательством **REAL** ([Качественный путь](#quality-path-to-done)) | Тихий рост парсера, Camunda/Flowable, полный BPMN 2.0 |
| Scorecard / docs / UX без завышения | Параллельные волны, которые только расширяют scope |

**Правила:**

1. **Сначала hardening** — баги, flaky gates, честность stub, runbook’и, остаточные soak важнее новых ID БЛ.
2. **Без тихого роста scope** — новые типы BPMN, DMN или смена движка требуют **нового ADR**; freeze subset ([ADR-0047](decisions/0047-custom-bpmn-subset-engine.md)) действует до этого.
3. **Отложенное остаётся отложенным** — OT Trust и живой ERP (БЛ-169) возобновляются только при именованной полевой/интеграционной задаче ([ready-for-field](../en/field-pilot-playbook.md#ready-for-field-gate-policy)). Доска: [parked-backlog.md](parked-backlog.md).
4. **Новые строки БЛ / фазы** — только blocker заказчика, compliance-гейт или закрытие пробела честности — не ширина конкурентного чеклиста.

Политика **не** отменяет Definition of Done 10/10; меняет **порядок атаки**: пригодная глубина уже существующего раньше новой поверхности.

Канон EN: [Execution policy](../en/roadmap.md#execution-policy--quality-over-features).

## Определение готовности — общая оценка 10/10 {#определение-готовности--общая-оценка-1010}

Продукт = **10/10**, когда **одновременно**:

1. **20 PRODUCTION-драйверов** с interop CI и **3 подписанных полевых пилота** — **не выполнено** (БЛ-140 Частичный; поле по именованной задаче).
2. **Пакет MES** — OEE + заказы + качество без custom Java; **хотя бы один живой ERP-коннектор** (БЛ-169) — не только stub.
3. **Агент ИИ** — ≥95 % регрессии с **живым LLM**, deploy без правок — **выполнено** по планке БЛ (52/52; opt-in `ISPF_LLM_SMOKE`).
4. **Историк** — 3 уровня, масштабные gates; AF-capable analytics (БЛ-200…).
5. **Безопасность** — MFA + ACL на переменную + опция strict tenancy (БЛ-153…155).
6. **HMI** — mimic 500 el @60 FPS (честно: CI ≥55; stretch unmocked ≥60), offline PWA 8 ч (БЛ-151, 152).
7. **Marketplace** — 10+ подписанных пакетов, 3 внешних партнёра (БЛ-183, 184).
8. **Scorecard** — 14 измерений ≥9,5 — **не выполнено** (~8,0/10).
9. **Честность OT** — ноль stub с меткой PRODUCTION (БЛ-191 — honesty scope в EN **Готово**; полевой хвост открыт).
10. **Compliance pack** — IEC 62443 / GAMP-lite docs (БЛ-192) — **выполнено** как documentation pack, **не** сертификация продукта.

Преждевременные Done без code-verified gates **отозваны**. Пригодный Done — ниже.

## Качественный путь к Done — рабочий продукт, не галочки {#quality-path-to-done}

**Цель:** фазы 25–33 закрыты, когда **реальный интегратор + оператор + OT-инженер** проходят production-сценарии без руки core-команды.

### Принципы

| # | Принцип | Отклоняет |
| - | ------- | --------- |
| 1 | **Доказательство REAL** — runtime + автотест + runbook | `mode: stub`, in-memory-only GA |
| 2 | **Подпись человека** на hot path | Self-certified Done без журнала |
| 3 | **Live gates** там, где заявлено live | Mocked FPS, schema-only agent CI, ERP `simulated` |
| 4 | **Честная зрелость** — PRODUCTION = код | Stub в PRODUCTION-матрице |
| 5 | **Повторяемость третьей стороной** | Демо только на ноутбуке мейнтейнера |
| 6 | **Field или lab SLO** | Скриншот без CI-регрессии |

В **Готово** только класс **REAL**.

### Когда БЛ может перейти Частичный → Готово

1. Критерии приёмки на **prod-like** профиле.
2. Интеграционный/e2e тест в CI **без stub** на проверяемом пути.
3. Runbook интегратора (шаги, rollback, ограничения).
4. Scorecard обновлён с путями в коде + именами тестов.
5. Нет открытого **P0 по честности** в домене.

### Четыре волны (порядок атаки)

| Волна | Фокус | Статус |
| ----- | ----- | ------ |
| **1** | OT trust, который можно поставить (фаза 25 + БЛ-191) | **Отложено** — см. [Backlog S31](#s31-wave-1-execution-backlog) |
| **2** | Операторский HMI (фаза 26 + shelving) | Lab Готово; field soak по playbook |
| **3** | Цех + бизнес-контур (историк, MES, ERP) | MES lab Готово; живой ERP отложен; полевые площадки открыты |
| **4** | Ров + масштаб (AI, analytics, ecosystem, security) | AI harness Готово; остаток soak / партнёры / scorecard |

Фаза 30 (CEP / process / BPMN) — **после** REAL operator + historian + MES, иначе автоматизируются stub. Дальнейшая глубина BPMN — только с заказчиком + ADR.

### Антипаттерны (не ставить Готово)

| Паттерн | Пример |
| ------- | ------ |
| Stub = PRODUCTION | `OpcDaDeviceDriver` в матрице |
| Фейковый ERP | Outbox `simulated` без live-коннектора |
| Фейковая AI regression | `nightly-stub-results.json` как proof ≥95 % |
| Фейковые партнёры | Claim Partner Portal GA при только DB directory |
| Mocked perf | e2e с mocked WebSocket |
| Smoke = production | MES только GA smoke |

### Backlog S31 — Волна 1 (parked) {#s31-wave-1-execution-backlog}

> **Отложено (14.07.2026).** OT Trust не в активном окне. Чеклист сохранён на случай **именованной полевой задачи на драйвер**. Активный S31 в плане 90 дней — AI, не этот backlog.

**Пригодный результат при возобновлении:** OT-инженер доверяет матрице; один пилот Modbus plant с ежедневным журналом soak.

| Gate | Доказательство |
| ---- | -------------- |
| Честная матрица | Ноль `PRODUCTION` у stub; CI-тест зелёный |
| Interop write | Round-trip в smoke для `modbus-tcp`, `mqtt`, `opcua` |
| Пилот запущен | Площадка названа, журнал дни 1–3 |
| Scorecard | Измерение OT с путями в коде |

Потоки A–D (честность матрицы, interop, пилот, edge stretch) и шаблон журнала soak — в EN: [S31 execution backlog](../en/roadmap.md#s31-wave-1-execution-backlog).
