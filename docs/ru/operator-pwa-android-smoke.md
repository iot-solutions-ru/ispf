# Проверка пульта оператора (PWA) на планшетах и смартфонах Android

> **Статус:** Stable — чеклист проверки установки и работы мобильного пульта оператора в браузере Android Chrome и автоматический тест Playwright (`e2e/pwa-android.spec.ts`). Метки зрелости: [doc-status.md](doc-status.md).

Этот документ описывает быструю 5-минутную проверку мобильного режима оператора ISPF на устройствах Android, а также соответствующие автоматические тесты в `apps/web-console`.

---

## 1. Установка ярлыка приложения на главный экран Android

1. Откройте адрес сервера ISPF по протоколу HTTPS в браузере Chrome (`https://<ваш-хост>/?mode=operator`) и войдите под учётной записью оператора.
2. В меню браузера выберите **«Установить приложение»** (или **«Добавить на главный экран»**).
3. Запустите приложение **ISPF** с рабочего стола Android — оно откроется в полноэкранном режиме без адресной строки браузера (`display: standalone`).

---

## 2. Контрольный список проверки (5 минут)

| Шаг проверки | Ожидаемое поведение | Автоматический тест в CI |
|--------------|---------------------|--------------------------|
| Запуск с ярлыка на главном экране (`start_url` с `mode=operator`) | Сразу открывается пульт оператора без дерева объектов администратора | `e2e/pwa-android.spec.ts` |
| Переключение вкладок экранов и панелей | Верхняя шапка и вкладки не перекрываются системными вырезами экрана | Проверка области просмотра Pixel 5 |
| Поворот экрана (книжная ↔ альбомная ориентация) | Сетка карточек перестраивается без горизонтальной прокрутки | Тест смены ориентации экрана |
| Включение режима полёта (обрыв сети) | Появляется аккуратная плашка автономного режима, кэшированная оболочка продолжает открываться | Тест перезагрузки Service Worker в офлайне |
| Выключение режима полёта (возврат сети) | Плашка пропадает, живые показания возобновляются без перезапуска приложения | Тест восстановления связи |

Запуск автоматического набора тестов локально:

```bash
cd apps/web-console
npm run test:e2e:preview
```
