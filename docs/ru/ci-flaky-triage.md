# Регламент разбора и устранения нестабильных автотестов в CI

> **Статус:** Internal — правила классификации, исправления и временной изоляции нестабильных («мигающих») тестов в конвейерах GitHub Actions. Метки зрелости: [doc-status.md](doc-status.md).

Этот документ задаёт порядок действий разработчиков при появлении случайных сбоев в тестах Gradle или Playwright.

---

## 1. Уровни критичности нестабильных тестов

| Уровень | Признак | Норматив реакции |
|---------|---------|------------------|
| **`P0`** | Сбой блокирует слияние веток в `main` или ломает ночной прогон более 2 раз подряд | Исправить (или временно изолировать с привязкой к задаче) в течение **24 часов** |
| **`P1`** | Сбой повторяется чаще 1 раза в неделю | Устранить причину гонки в течение текущего спринта |
| **`P2`** | Редкий единичный сбой (реже 1 раза в месяц на загруженном раннере) | Взять на заметку в бэклог тестирования |

---

## 2. Порядок разбора сбоя

1. **Воспроизвести локально** командой из раздела **[Тестирование платформы (`testing.md`)](testing.md)** или по логу шага в GitHub Actions.
2. **Устранить первопричину:** заменить жёсткие паузы `Thread.sleep` на явное ожидание условия, изолировать порты и тестовые данные, добавить аннотацию `@Isolated` для тяжёлых тестов с сетевыми туннелями.
3. **Если немедленное исправление невозможно — оформить временный карантин (не более чем на 14 дней):**
   ```java
   @Disabled("ci-flake #1234 — временно отключён до 2026-07-20")
   ```
   ```typescript
   test.skip(true, "ci-flake #1234 — временно отключён до 2026-07-20");
   ```

---

## 3. Профили конвейеров CI

| Файл конвейера | Когда запускается | Что включает |
|----------------|-------------------|--------------|
| [`.github/workflows/ci.yml`](../../.github/workflows/ci.yml) | На каждый Pull Request | Быстрый набор `testPrFast`, проверка сборки и линтеры (без многоминутных нагрузочных тестов) |
| [`.github/workflows/nightly.yml`](../../.github/workflows/nightly.yml) | По ночному расписанию и вручную (`workflow_dispatch`) | Полный прогон всех модулей и интеграционных проверок |
| [`.github/workflows/load-test.yml`](../../.github/workflows/load-test.yml) | По ночному расписанию | Нагрузочные проверки конвейера событий |
| [`.github/workflows/e2e-live.yml`](../../.github/workflows/e2e-live.yml) | Еженедельно и вручную | Браузерные сквозные тесты Playwright |
