# Сравнительная оценка зрелости подсистем ISPF

> **Статус:** Stable — объективная оценка готовности подсистем платформы по коду, автотестам и стендовым испытаниям. Метки зрелости: [doc-status.md](doc-status.md).

В этой таблице сведена фактическая зрелость 14 основных направлений ISPF (по 10-балльной шкале относительно специализированных промышленных платформ класса Ignition, Kepware, OSIsoft PI и Siemens Opcenter) на основе проверки исходного кода, автотестов и протоколов стендовых испытаний.

**Версии (не смешивать):** pin **0.9.207** = полный competitive audit 2026-09-09 (оценки ниже). Pin **0.9.102** = предыдущий code audit. Текущий `main` **0.9.208** позже аудита — **не** повторный scored matrix; новые коммиты ≠ новый pin. Program wave 8 (~9.8) по-прежнему **отозвана**.

| **10** | **Безопасность, разграничение прав и мультитенантность** | **8,5** | Реализовано | OIDC/Keycloak, двухфакторная защита TOTP, ролевой и пообъектный доступ (`ACL`), изоляция арендаторов, шифрование секретов ([security.md](security.md)) |

| **12** | **Витрина решений и пакеты расширений** | **6,5** | Реализовано | Установка бесплатных и платных пакетов `bundle.json`, `symbol-pack`, `analytics-pack` и `ui-pack` с проверкой цифровой подписи RSA ([marketplace.md](marketplace.md)) |
| **13** | **Документация и инструменты разработчика** | **8,5** | Реализовано | Двуязычная документация, CLI `ispf`, SDK драйверов (`driver-ddk`), архитектурные решения (ADR) |

**Средняя оценка по всем 14 направлениям: ~8,0 из 10.**
