ISPF

Серверная платформа промышленной автоматизации, SCADA и IoT на вашем контуре — опрос оборудования, экраны оператора, тревоги, архив историй и процессы BPMN в едином дереве объектов.

Единая модель площадки

Вместо связки разрозненных шлюзов, баз историй, редакторов мнемосхем и систем оповещений все элементы в ISPF работают как узлы одного иерархического дерева — с общим API, правами доступа и веб-консолью.

  • Дерево объектов Типизированные переменные, формулы расчёта, события и функции через REST API и WebSocket.
  • Экраны оператора и SCADA Конструктор дашбордов, графики трендов, мнемосхемы P&ID и подключение собственных веб-приложений на React.
  • Тревоги и процессы BPMN Уставки на языке CEL с гистерезисом, корреляторы серий событий и маршруты смены с рабочей очередью задач.
  • Драйверы и пакеты решений Более 160 пакетов протоколов (Modbus, OPC UA, S7, MQTT, SNMP, МЭК-104, DNP3, JDBC) и поставка прикладных решений пакетом bundle.json без доработки ядра.

Для инженеров и сменных операторов

Консоль администратора для настройки модели и полноэкранный режим оператора для дежурной смены.

Запуск на своей машине

Готовый архив со встроенной файловой БД H2 или контейнер Docker (PostgreSQL для пробы не нужен). Вход по умолчанию: admin / admin.

docker pull ghcr.io/iot-solutions-ru/ispf-server:latest
docker run --rm -p 8080:8080 -v ispf-data:/opt/ispf/data ghcr.io/iot-solutions-ru/ispf-server:latest
# открыть http://localhost:8080
